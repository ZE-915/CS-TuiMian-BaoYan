# 一、行列式

## 行列式的计算

**什么是行列式？**

行列式是一个值，不是一个矩阵。行数 = 列数

设矩阵为 A，则 det（A）为或|A|行列式。

<img src="assets/image-20260720194521047.png" alt="image-20260720194521047" style="zoom: 33%;" />

一阶行列式：它的值等于里面元素的本身，行列式符号不是绝对值符号。

**如何计算行列式？**对角线法则。

<img src="assets/image-20260720195027279.png" alt="image-20260720195027279" style="zoom:33%;" />

特殊的行列式

+ 上三角行列式：主对角线下方全是0，行列式的值为对角线乘积
+ 下三角行列式：主对角线上方全是0
+ 对交行列式：主对角线上下全是0，主对角线非0

<img src="assets/image-20260720202707774.png" alt="image-20260720202707774" style="zoom: 40%;" />

## 全排列、兑换

n级排列：n个不重复的自然数按照任意顺序排成的一行数。

+ 奇排列：逆序数为奇数的排列
+ 偶排列：逆序数为偶数的排列

逆序数：n级排列中，如果对于一个数$i_k$，在这个数的前面有1个比他大的数$i_{k - m}$，则称这两个数构成一个**逆序**，统计这个排列中所有**逆序的总和**即为该**排列的逆序数**

<img src="assets/image-20260720201231089.png" alt="image-20260720201231089" style="zoom:33%;" />

对换：将排列中的两个数对换一次，则排列的奇偶性会发生改变

<img src="assets/image-20260720201901492.png" alt="image-20260720201901492" style="zoom:33%;" />

## 行列式的性质

+ 转置不变：转置后行列式值不变，上三角行列式、下三角行列式互为转置行列式
+ 对换变号：对换行列式的两行（列），行列式要变号
  + 如果一个行列式有两行（列）相同，则该行列式为0
+ 提公因子：如果行列式某行（列）的元素有公因子，则该公因子可以提到行列式的外面
  + 如果每行（列）都有公因子k，则一共提出的公因子为$k^n$
  + 如果行列式两行（列）成比例，则该行列式为0
  + 如果行列式的某一行（列）全为0，则该行列式为0
+ 拆项求和：如果行列式的一整行（列）都是两项之和，则该行列式可以拆成两个行列式相加

+ 倍加不变：将某行（列）的k倍加到另外一行（列）中，行列式不变
