# 模拟面试的网站

[网址点这里](https://www.yantutong.online/xiaosu/interview-coach)

需要购买会员，最少的是七天，小红书购买相对便宜一些，可以搜索店名【小苏资料站的店】，不是广哈。

一天可以开启三次面试，可以开启然后暂存，即使会员过期暂存的面试也可以继续作答，一个周会员一共21次可以完美利用，不管是论文还是项目的问题，大部分都可以涉及到。

当然也可以直接跟**GPT或者豆包**进行交流提问，也不需要花钱，只不过我没有试过。



# 没有科研项目怎么办

1、如果时间来得及，找老师、找实验室，自己去发邮件或者打电话或者其他联系方式，跟老师讲。

2、如果时间来不及，只剩半年左右就要面试了（我觉得这个时间跟第一条相比很短了），上kaggle平台找模型，自己学习、复现，看各人吧还是。参考视频：[【保研/考研简历加分】20分钟拿下科研项目](https://www.bilibili.com/video/BV1rx4y1i7oc)，太感人了up不卖课。PS：不是本人，B站大佬还是很多的。
